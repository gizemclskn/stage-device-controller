\# Stage Device Controller



\*\*TR:\*\* Ağ üzerindeki bir sahne ışık/ses cihazını TCP socket ile kontrol eden Android (Java) uygulaması. Gerçek donanım yerine Python ile yazılmış bir simülatör sunucu kullanılır.



\*\*EN:\*\* Android (Java) app that controls a stage lighting/audio device over TCP sockets. A Python simulator server stands in for the real hardware.
